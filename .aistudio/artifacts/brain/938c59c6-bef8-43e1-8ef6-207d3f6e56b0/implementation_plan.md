# خطة تنفيذ ميزة «مكافأة الانتماء» وبرنامج ولاء المشتركين — طلقة نت (Talqa Loyalty Vault)

نظام ولاء متطور يحفّز المشتركين على الاحتفاظ بكروتهم القديمة والبقاء حصرياً ضمن شبكة طلقة نت، من خلال استبدال كل 10 كروت مستهلكة بفرصة ربح فورية لكروت جديدة عبر لعبة تفاعلية مشوقة مع ضوابط أمنية مشددة تمنع التحايل والتكرار.

---

> [!IMPORTANT]
> **القرارات المحورية وخيارات النظام المطروحة:**
> 1. **آلية فحص الكروت:** التحقق المزدوج من قاعدة بيانات كروت الشبكة والمايكروتك، مع وسم كل كرت مُدخل بحالة `loyalty_redeemed` (مستهلك في المكافأة) لمنع أي محاولة لإعادة استخدامه.
> 2. **تصميم اللعبة التفاعلية:** عجلة حظ سينمائية نيون مستوحاة من هوية طلقة نت، مع مؤشر سهم ديناميكي وأصوات دوران وفوز تشويقية (`Web Audio API`).
> 3. **صندوق الجوائز:** بنك كروت خاص في لوحة الإدارة يشحنه مدير الشبكة بكروت جوائز مسبقة، مع إمكانية ضبط احتمالات الفوز لكل فئة.

---

## 1. النظرة الاستراتيجية والتسويقية (Marketing & Product Value)

### لماذا تُعد هذه الفكرة ضربة تسويقية رابحة لشبكة طلقة نت؟
- **رفع معدل الاحتفاظ بالعملاء (Customer Retention):** المشترك لن يشتري كرت شبكة أخرى منافسة في الحي، لأنه سيكون حريصاً على تجميع كروت «طلقة نت» للوصول إلى الكرت العاشر.
- **إعادة تدوير القيمة (Recycling Perceived Value):** تحويل الكرت الورقي المستهلك من "قمامة ورقية" إلى "عملة رقمية تراكمية".
- **عنصر التشويق (Gamification):** تحويل عملية الشراء التقليدية إلى متعة وتحدٍ وتنافس بين أهالي الحي والأصدقاء.

## 2. تجربة المستخدم والمسار التفاعلي (User Experience & Flow)

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. تبويب مكافأة الانتماء ➔ 2. إدخال وفحص 10 كروت ➔ 3. عجلة الحظ ➔ 4. استلام الكرت │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
       ┌───────────────────────────┴───────────────────────────┐
       ▼                                                       ▼
[فحص قاعدة بيانات الشبكة]                                [ختم الكروت المستبدلة]
- الكرت مسجل في الشبكة                                    - نقل حالة الكروت إلى:
- الكرت مستهلك أو منتهي                                   "loyalty_redeemed"
- لم يُستبدل سابقاً                                       - حفظ سجل المعاملة وتاريخها
```

### خطوات تجربة المشترك:
1. **شاشة الولاء التفاعلية:**
   - شريط تقدم ذكي (0 / 10 كروت).
   - خياران للإدخال: **لصق سريع دفعة واحدة** أو **إدخال كرت تلو الآخر**.
2. **الفحص الأمني اللحظي:**
   - يظهر لكل كرت شارة فحص خضراء مع فئة الكرت الأصلي وتاريخ استهلاكه.
   - إذا كان الكرت مكرراً أو غير مسجل أو لم يستهلك بعد، يتم تنبيه العميل فوراً.
3. **تفعيل بوابة لعبة الحظ:**
   - بمجرد اكتمال 10 كروت صالحة، تُغلق الكروت ويتم حرقها في السجل برمز ختم خاص.
   - ينفتح زر ذهبي متوهج: **«أدر عجلة المكافآت واربح كرتك الآن ⚡»**.
4. **لعبة عجلة الحظ (Neon Fortune Wheel):**
   - عجلة دائرية مقسمة لقطاعات تمثل فئات كروت الشبكة (1000 ريال، 2000 ريال، 4000 ريال VIP، إلخ).
   - مؤشر السهم يهتز مع أصوات النقر، ثم يستقر على الجائزة الرابحة مع قصاصات احتفالية (Confetti) ومؤثرات صوتية.
5. **استلام الكرت فوراً:**
   - يظهر كرت الجائزة الجديد بكامل تفاصيله (الكود، الباقة، الصلاحية).
   - زر «نسخ الكود» وزر «تسجيل الدخول بهذا الكرت الآن مباشرة».
   - حفظ الكرت في "محفظة جوائزك" في المتصفح لعدم ضياعه.

---

## 3. الضوابط الأمنية لمنع التلاعب (Anti-Fraud & Rules)

1. **منع التكرار نهائياً (One-Time Burn):**
   - بمجرد إدخال الكرت في مكافأة ناجحة، يُسجل الكود في قائمة `burned_loyalty_cards`. أي محاولة لإدخاله مجدداً في أي وقت من أي جهاز تظهر رسالة: *"هذا الكرت تم استبداله مسبقاً في برنامج الولاء بتاريخ (اليوم والساعة)"*.
2. **التحقق من انتهاء واستهلاك الكرت:**
   - منع استخدام الكروت الجديدة غير المستعملة حتى لا يخسر المشترك كروته الفعالة بالخطأ.
3. **صندوق الجوائز للمدير (Admin Rewards Pool):**
   - إضافة قسم في لوحة الإدارة: **«إدارة كروت جوائز الولاء»**.
   - يتيح لك شحن كروت حقيقية، أو استيرادها كجوائز جاهزة، مع إمكانية تحديد وزن ونسبة الفوز لكل فئة (مثلاً: 60% كروت 1000 ريال، 30% كروت 2000، 10% كروت 4000 VIP).

## 4. المكونات البرمجية والهيكلية (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────┐
│                       تطبيق طلقة نت                          │
│                                                             │
│  ┌───────────────────────┐       ┌───────────────────────┐  │
│  │ LoyaltyRewardView.tsx │ <---> │  cardsDatabase.ts     │  │
│  │ (واجهة الولاء والعجلة)│       │  (سجل الكروت المحروقة)│  │
│  └───────────────────────┘       └───────────────────────┘  │
│             │                                │              │
│             ▼                                ▼              │
│  ┌───────────────────────┐       ┌───────────────────────┐  │
│  │ FortuneWheelCanvas.tsx│       │ AdminLoyaltyVault.tsx │  │
│  │ (محرك العجلة والأسهم) │       │ (صندوق كروت الجوائز)  │  │
│  └───────────────────────┘       └───────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- **`src/components/LoyaltyRewardView.tsx`**: واجهة المستخدم الكاملة للمكافأة، تضم سلة إدخال الـ 10 كروت، شريط التقدم، ومحفظة الكروت الرابحة.
- **`src/components/FortuneWheel.tsx`**: محرك العجلة التفاعلي بتقنية Canvas أو CSS Transforms عالية النعومة مع سهم التوجيه.
- **`src/utils/loyaltyManager.ts`**: وحدة المعالجة المركزية، مسؤولة عن التحقق، فحص الكروت المكررة، سحب الجوائز العشوائية الموزونة، وتخزين السجلات في IndexedDB و LocalStorage.
- **لوحة الإدارة:** تبويب مخصص لإدارة وتغذية صندوق الجوائز ومراقبة سجل العمليات.
